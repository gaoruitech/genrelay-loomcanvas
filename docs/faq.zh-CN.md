# 常见问题

[English](faq.md)

自己部署实例的人常会遇到的问题。画布使用上的问题，应用内的教程（「?」按钮）里有单独的常见问题，也可以看[使用指南](user-guide.zh-CN.md)。

## 模型与成本

### 节点上显示「成本未知」

这个模型没有与当前参数对得上的价格。LoomCanvas 不自带任何价格：它无从知道你的上游向你收多少钱。

1. 打开「设置 → 模型」，找到模型，点「设置价格」。
2. 填上你实际支付的单价。价格随分辨率或时长变化的，在「价格随什么变化」里选对应的项，每个档位填一行。

价格表里没有当前分辨率或时长对应的那一行，同样是「成本未知」。按 token 计价的对话模型在运行前显示未知，运行后如果上游返回了 token 用量才有成本。没有价格的模型照样可以运行。详见[模型接入](providers.zh-CN.md#价格)。

### 模型下拉是空的，或者提示「还没有可用的模型」

按这个顺序检查：

1. 「设置 → 模型接入」：有没有接入，是否启用？点一下「测试连接」。
2. 「设置 → 模型」：模型是否启用？
3. 节点类型对不对？视频编辑节点只列出视频编辑模型。OpenAI 兼容接口和 Gemini 这两种接入完全不提供视频模型。
4. OpenAI 兼容接口如果没有 `/v1/models`，或者列出来的名字识别不准，就不要依赖自动识别，直接把模型名填进「对话模型」和「图片模型」两个字段。
5. 第一次读取列表时上游连不上的话，列表最多会空五分钟。保存或测试一次接入会刷新它。

### 需要的模型没出现，或者列出了不该有的

模型列表来自接入：高睿的图片和视频模型是固定清单，其他从上游列表里发现的模型靠名字识别。识别可能出错。不该出现的在「设置 → 模型」里停用；OpenAI 兼容接口和 Gemini 可以在接入表单里按名字写明要哪些模型。

### 重新运行节点会再计一次费吗

会。每次运行都会向上游提交一个新任务。对已经有结果的节点重新运行前，画布会先让你确认。之前的结果留在节点的历史版本里。

### 这里的金额和真实账单一致吗

不一定。金额是按你填的价格、在提交运行时算出来的（对话模型则按返回的 token 用量算）。以上游的账单为准。失败的运行在这里不计花费，即使上游已经为它收了钱。

## 素材

### 视频编辑失败，提示「…需要公网可访问的地址…」

有些输入只能以地址的形式交给上游：视频编辑的原视频、部分视频模型的参考图、对话里的视频。上游必须能从公网下载这个地址。

两种解决办法选一个：

- 把 `PUBLIC_URL` 设成实例的公网地址（例如 `https://canvas.example.com`），并确认它真的能从公网访问；或者
- 改用对象存储（`STORAGE_DRIVER=s3` 或 `oss`），并配好公开地址前缀。

使用本地存储时，画布上已有的文件不用重新上传：它们的地址是站内相对地址，交给上游时才拼上 `PUBLIC_URL`。`localhost` 和内网地址永远不算公网地址。见[模型接入](providers.zh-CN.md#素材怎么送到上游)。

### 从另一台电脑打开，图片全是破图

使用本地存储时，文件是按站内相对地址（`/files/<key>`）保存的，从哪个地址打开应用就从哪个地址加载。所以当前版本存下的文件不应该出现这个问题，不管 `PUBLIC_URL` 是什么。

早期版本保存的画布仍可能出现：那时存的是绝对地址，例如 `http://localhost:3000/files/…`，另一台电脑的浏览器访问不到。把这些文件重新上传，或者重新运行节点。见[部署](deployment.zh-CN.md#public_url)。

### 缩略图是怎么回事，为什么有的没有

- 节点里显示的是一张小的 WebP 缩略图（最长边 512 像素），不是原图；查看大图和下载用的始终是原图。
- 缩略图在上传文件或转存结果时生成。使用本地存储时，缺的那张会在第一次被请求时现做一份并保留。
- 只有 PNG、JPEG、WebP、BMP、AVIF 图片有缩略图。视频、GIF、HEIC 没有，直接显示原文件。
- 很小的上传图片（最长边不超过 512 像素）自己就是自己的缩略图。
- 使用对象存储时没有「请求时现做」。刷新页面后，浏览器不再记得缩略图地址的图片会直接显示原图。这只是慢一些，不是坏了。

### 上传失败，或提示文件太大

有两道限制，取较小的：

| 限制 | 默认 | 在哪里 |
| --- | --- | --- |
| 服务端，每个文件 | 50 MB | `MAX_UPLOAD_MB`。画布从服务端读到这个值，超过的文件在上传前就会被拦下。 |
| 反向代理 | 各不相同（nginx 不配置时是 1 MB） | `client_max_body_size` 或类似配置 |

如果收到 `413`，而且看起来不是 LoomCanvas 的提示，那就是代理返回的。只接受图片和视频文件，按内容判断。

### 结果下载失败：「不允许访问内网地址」

上游返回的结果链接指向内网或本机地址，服务端拒绝去取。如果上游是你自己网络里的模型服务，把它的主机加到 `SSRF_ALLOW_HOSTS` 并重启。请先读[安全](security.zh-CN.md#ssrf-防护)。

## 运行

### 运行好像卡住了

- 长时间**排队中**：并发名额都占满了。调大「设置 → 限制 → 并发数」，或者等一等。
- 长时间**运行中**：上游还没出结果。运行不会无限等下去：默认图片运行 10 分钟后判失败，视频运行 30 分钟（「设置 → 限制」）。对话请求 5 分钟后失败（`chatTimeoutSec`）。
- 运行中的节点上有「取消运行」按钮。排队中或进行中的运行也可以通过接口取消：`POST /api/runs/<id>/cancel`（见 [API](api.md#models-and-runs)）。运行的 id 就是 `GET /api/admin/usage/records` 返回的记录里的 `id`。
- 服务端重启后，排队中的运行和已经拿到上游任务号的运行会自己接着跑。时限从最初提交时算起，重启不会让它变长。服务端停止时正在发出请求的运行则会失败，见下面的「服务在提交这个任务时停止了…」。
- 如果经常超时，而上游最后其实出了结果，就把超时调大。如果超时发生在「下载结果」这一步，调大 `downloadTimeoutSec`（见[配置](configuration.zh-CN.md#管理设置)）。

失败原因在节点的任务详情里，也在「设置 → 用量」里。意料之外的问题，服务端日志里信息更多：`docker compose logs app`。

### 「已有 500 个未完成的运行」

排队中和进行中的运行达到 500 个时，新的运行会被拒绝。等一部分跑完即可。大批量的批量运行可能碰到这个上限。

### 「服务在提交这个任务时停止了…」

那次运行的请求已经发出、上游任务号还没拿回来的时候，服务端停了（重启、升级、崩溃、内存不足、被强制结束）。它不会被再次提交，因为上游可能已经建好任务并计费了。请到上游查一下记录，需要的话再运行一次节点。

在同一个请求里直接返回结果的接入（OpenAI 兼容接口的图片、Gemini），以及大语言模型节点和视频分析节点，从来没有任务号，所以这类运行只要在服务端停止时正在进行，就是这个结果。

### 点「运行全部」没反应

「运行全部」和「运行此分支」需要链路末端有一个成品节点。加一个成品节点，把结果连过去；或者用单个节点上的运行按钮。

## 访问与启动

### 改了 SECRET_KEY 之后，保存的 API Key 不能用了

接入的 Key 是用 `SECRET_KEY` 加密的。换了密钥就解不开，运行会失败并提示「无法解密该接入的 API Key（SECRET_KEY 是否被改过？），请重新填写」。

- 旧的 `SECRET_KEY` 还在：改回去并重启，一切恢复。
- 找不回来了：打开「设置 → 模型接入」，逐个编辑接入，重新填写 API Key。其他数据不受影响。

### 怎么重置访问口令

修改 `.env`（不用 Docker 时是 `server/.env`）里的 `ACCESS_PASSWORD`，然后重启：

```bash
docker compose up -d
```

数据库里没有需要重置的东西。所有人都会被退出，用新口令重新登录。把值清空就是完全关闭登录。

### 「尝试次数过多，请稍后再试」

触发了登录限流：每个客户端每 10 分钟 10 次，合计 300 次。等十分钟，或者重启服务端清空计数。

如果在反向代理后面所有人都碰到这个提示，说明服务端把所有访问者都当成了代理。设置 `TRUST_PROXY=1`（前面代理的层数）；`TRUST_PROXY=true` 不被接受。

### 服务端一启动就退出

看日志的最后几行（`docker compose logs app`）。常见原因：

| 信息里包含 | 原因 |
| --- | --- |
| `SECRET_KEY is required` | 没设，或不足 16 位。 |
| `must be an integer between` / `must be one of` | 某个环境变量的值不合法，信息里会指出是哪个。 |
| `TRUST_PROXY must be …` | `TRUST_PROXY` 既不是代理层数（1 到 10），也不是地址列表。`true` 和主机名都会被拒绝。 |
| `needs the "…" package` | `STORAGE_DRIVER=oss` 但没有安装 `ali-oss`（或者安装时用了 `--omit=optional`，缺 `s3` 的 SDK）。见[部署](deployment.zh-CN.md#在-docker-镜像里使用对象存储)。 |
| `STORAGE_DRIVER=s3 requires …` | 某个必填的存储变量为空。 |
| `WEB_DIST is set to … but there is no index.html` | 前端没有构建，或路径不对。 |
| `BILLING_HOOK could not be loaded` | 钩子文件不存在，或加载时抛错。 |
| MongoDB 连接错误 | 按 `MONGODB_URI` 连不上数据库。 |

### 磁盘越用越多

生成的文件默认永久保留。可以：

- 设置「设置 → 限制 → 结果保留天数」。早于这个天数的运行，结果文件会被删除；还显示着它们的画布会出现破图。
- 用量记录本身很小，也可以在「设置 → 用量 → 清理早于这一天的记录」里删除旧的。它只删记录，不删文件。
- 删除画布或资产不会删除它们的文件。

## 适用范围

### 几个人能各用各的账号共用一个实例吗

不能。只有一个共用口令和一份数据。见[安全](security.zh-CN.md#访问口令)。

### 我的上游不是这三种接入类型

如果它用的是 OpenAI 的对话或图片接口格式，用「OpenAI 兼容接口」。否则写一个接入只需要一个文件：[编写模型接入](writing-a-provider.zh-CN.md)。

### 这些接入对着真实服务测过吗

在本项目里目前还没有。它们是对着假上游测的，固定了请求和响应的格式。S3 和 OSS 两个存储驱动的代码已经写好，同样还没有对着真实的桶跑过。请在自己的环境里验证，并欢迎反馈结果。
