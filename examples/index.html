LoomCanvas integration examples

Each page is a "host product" that builds LoomCanvas in. See docs/integration.md.

  1. host-page: the whole app inside a plain HTML page, without LoomCanvas' shell, with the host's own sign-in. Needs a running LoomCanvas server.
  2. vue-editor: a Vue host using <LoomCanvasEditor> with the HTTP adapter. Needs a running LoomCanvas server.
  3. plain-editor: a framework-free host using mountEditor with the memory adapter. Needs no server at all.
